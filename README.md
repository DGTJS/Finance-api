# Finance-api

Projeto financeiro utilizando Node.js e TypeScript

# Sobre o projeto

Projeto financeiro de estudo para praticar o uso de Node.js e TypeScript, o projeto tem o intuito de gerenciar a finanças pessoais e familiares, com dashboard, relatórios e planejamento financeiro.
